Privacy Policy

Last updated: 25 October 2026

Freepik Cloud Pipeline ("the app") is a private automation tool used only by its owner. This policy explains how the app handles Google user data.

Data the app accesses

With the owner's permission (Google OAuth, Google Drive scope), the app reads and writes files inside the owner's own workflow folder in Google Drive: generated photos, a metadata CSV file, review sheets, daily summaries, and prompt history. It does not access contacts, email, or any other Google data.

How the data is used

The data is used only to save the app's results to the owner's Drive and to avoid creating duplicate photos. It is not used for advertising, profiling, or training AI models.

Storage and security

The OAuth token is stored in Google Cloud Secret Manager inside the owner's own Google Cloud project and is only readable by the app's service account. Working files are kept in a private Cloud Storage bucket in the same project.

Sharing

The app does not sell, share, or transfer Google user data to anyone.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's Google Cloud resources removes the stored token and working files.
